# Riemann-Hypothesis
Modelo de campo de Fock nulo que reproduce los ceros de Riemann mediante barrido dimensional inverso (8D→11D). Matriz densidad factorial con paridad, validada por reverse exacto (11D→8D), compactificación a masa de Dirac 5D y proof strés paramétrica que confirma ceros móviles vs invariantes topológicos. Espectro: 14.1347, 21.0220, 25.0108, 30.4249.
